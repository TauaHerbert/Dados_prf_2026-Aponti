# 📊 Curso de Análise de Dados - Aponti

Bem-vindo ao repositório do Curso de **Análise de Dados**. 

Este espaço foi criado para organizar e documentar todas as atividades, exercícios e projetos práticos desenvolvidos ao longo da primeira etapa da formação. O objetivo central deste repositório é servir como um portfólio de evolução acadêmica e técnica.

## 🗂️ Estrutura do Repositório

O repositório está dividido em Modulos principais, refletindo a trilha de aprendizagem do curso. Cada pasta contém os arquivos executados e um descritivo interno específico sobre a atividade daquela unidade.

### 🗂️ Modulo 1

* **[📁 Unidade 1](Modulo-1/Unidade%201)**: Introdução aos conceitos fundamentais e primeiros passos com os dados.
* **[📁 Unidade 2](Modulo-1/Unidade%202)**: Estruturação, manipulação e tratamento inicial das bases de dados.
* **[📁 Unidade 3](Modulo-1/Unidade%203)**: Aplicação de lógicas de análise exploratória e extração de insights.
* **[📁 Unidade 4](Modulo-1/Unidade%204)**: Consolidação dos conhecimentos do módulo, sumarização e conclusão das análises.
