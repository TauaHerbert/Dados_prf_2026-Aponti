# 📊 Curso de Análise de Dados - Módulo 1

Bem-vindo ao repositório do **Módulo 1** do Curso de Análise de Dados. 

Este espaço foi criado para organizar e documentar todas as atividades, exercícios e projetos práticos desenvolvidos ao longo da primeira etapa da formação. O objetivo central deste repositório é servir como um portfólio de evolução acadêmica e técnica.

## 🗂️ Estrutura do Repositório

O repositório está dividido em 4 unidades principais, refletindo a trilha de aprendizagem do curso. Cada pasta contém os arquivos executados e um descritivo interno específico sobre a atividade daquela unidade.

* **[📁 Unidade 1](./Unidade%201)**: Introdução aos conceitos fundamentais e primeiros passos com os dados.
* **[📁 Unidade 2](./Unidade%202)**: Estruturação, manipulação e tratamento inicial das bases de dados.
* **[📁 Unidade 3](./Unidade%203)**: Aplicação de lógicas de análise exploratória e extração de insights.
* **[📁 Unidade 4](./Unidade%204)**: Consolidação dos conhecimentos do módulo, sumarização e conclusão das análises.

## 🛠️ Tecnologias e Ferramentas Utilizadas
* Python
* Lógica de Programação e Estrutura de Dados
* Git e GitHub (Versionamento)
