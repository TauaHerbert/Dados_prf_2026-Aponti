# 📚 Módulo 2: Aprofundamento em Análise de Dados

Bem-vindo ao segundo módulo do curso. Após a construção da base de manipulação de dados e fundamentos estatísticos trabalhados no Módulo 1 (Unidades 1 a 4), esta etapa avança para a interpretação de cenários complexos, extração de *insights* investigativos e construção de relatórios analíticos profissionais.

## 🗂️ Estrutura das Unidades

### 📍 Unidade 5: Análise Exploratória de Dados (EDA) Aplicada
Foco na execução do roteiro completo de EDA. O projeto central desta unidade é uma investigação profunda sobre a letalidade em acidentes rodoviários, utilizando dados abertos reais da PRF para contrastar volume absoluto com risco proporcional.
