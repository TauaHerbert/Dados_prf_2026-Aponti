# 📚 Módulo 2: Aprofundamento em Análise de Dados

Bem-vindo ao segundo módulo do curso. Após a construção da base de manipulação de dados e fundamentos estatísticos trabalhados no Módulo 1 (Unidades 1 a 4), esta etapa avança para a interpretação de cenários complexos, extração de *insights* investigativos e construção de relatórios analíticos profissionais.

## 🗂️ Estrutura das Unidades

### 📍 Unidade 5: Análise Exploratória de Dados (EDA) Aplicada
Foco na execução do roteiro completo de EDA. O projeto central desta unidade é uma investigação profunda sobre a letalidade em acidentes rodoviários, utilizando dados abertos reais da PRF para contrastar volume absoluto com risco proporcional.
👉 *[Acessar material e relatório da Unidade 5](./Unidade_5/README.md)*

### 📍 Unidade 6: Visualização de Dados Avançada e Storytelling
Desenvolvimento de narrativas visuais orientadas a negócios. Abordagem sobre as melhores práticas para desenhar gráficos claros, remover ruídos visuais e apresentar dados de forma que direcionem a tomada de decisão.

### 📍 Unidade 7: Validação de Hipóteses e Correlações
Aprofundamento matemático das análises. Estudo de matrizes de correlação (como Pearson), identificação de redundâncias em *datasets* e técnicas para evitar confusão entre correlação e causalidade.

### 📍 Unidade 8: Projeto de Fechamento do Módulo
Desafio prático consolidando as competências das unidades 5 a 7. Construção autônoma de um relatório executivo de ponta a ponta, partindo da higienização da base até a síntese dos achados acionáveis.
