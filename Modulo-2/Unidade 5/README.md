# Análise Exploratória de Dados (EDA) - Letalidade em Acidentes Rodoviários

## 📌 Sobre o Projeto
Este projeto apresenta um Relatório Analítico focado na base de Dados Abertos da Polícia Rodoviária Federal (PRF). O objetivo principal é investigar como a infraestrutura viária, fatores ambientais e o volume de tráfego influenciam o risco de óbito (letalidade) nas estradas federais, isolando o real perigo do simples volume de ocorrências.

## 🎯 Principais Achados
* **O Paradoxo da "Avenidização":** Municípios com grande trânsito urbano lideram em volume de acidentes, mas possuem baixíssima letalidade, pois congestionamentos forçam a redução da velocidade média (colisões leves).
* **O Risco da Baixa Visibilidade:** Ocorrências durante a "Plena Noite" concentram taxas de letalidade extremas (chegando a 38,2% em atropelamentos).
* **Infraestrutura Crítica:** A combinação de curvas em pistas simples provou ser o cenário mais letal da rodovia (14,2% de letalidade), facilitando colisões frontais devido à ausência de barreiras físicas e força centrífuga.

## 🛠️ Ferramentas Utilizadas
* **Análise e Tratamento:** Python (Pandas)
* **Visualização de Dados:** Matplotlib e Seaborn (Heatmaps, Gráficos de Barras, Séries Temporais)
* **Documentação:** Estruturação de relatórios executivos
