Este diretório centraliza projetos práticos focados em gerenciamento e análise de dados utilizando **SQL com SQLite**. Os projetos simulam cenários reais do mercado, desde a administração de um banco de dados relacional até a extração de inteligência analítica.

## 📂 Estrutura do Diretório

Abaixo está o resumo do que você encontrará em cada pasta deste repositório:

### 1. `Projeto Escola_tech`
* **Arquivo Principal:** `missao_escola_tech.sql`
* **Resumo do Projeto:** Simula a rotina de um Analista de Banco de Dados atuando na transição e manutenção do sistema de uma instituição de ensino. O código abrange operações de CRUD, auditoria de dados, alteração de estrutura de tabelas e aplicação de regras de negócio condicionais para classificar o status dos alunos (Aprovado, Recuperação, Reprovado).

### 2. `SQL com SQLite`
* **Arquivo Principal:** `acidentes_prf_2025.sql`
* **Resumo do Projeto:** Um projeto com foco profundo em *Data Analytics* utilizando dados abertos da Polícia Rodoviária Federal (PRF). O script realiza análise exploratória (EDA), cálculo de métricas de letalidade, cruzamento de fatores de risco (rodovias, clima, fase do dia) e criação de *Views* consolidadas para alimentar ferramentas de Dashboard.
